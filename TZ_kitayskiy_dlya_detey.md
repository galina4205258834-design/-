# Техническое задание: страница «Китайский язык для детей»

## 1. Цель страницы

Лендинг/раздел сайта школы китайского языка, продвигающий курсы китайского языка для детей (онлайн и в Москве), с целью:
- привлечения органического трафика по семантике «китайский язык для детей»;
- конвертации посетителей в заявки (пробный урок / консультация).

## 2. Целевая аудитория

- Родители детей 5–17 лет, рассматривающие изучение китайского с нуля.
- Родители школьников, готовящихся к ЕГЭ или олимпиадам по китайскому языку.
- Родители, ищущие очные курсы в Москве или онлайн-формат.

## 3. Анализ конкурентов (страницы-аналоги)

1. https://rocketchinese.ru/programs/dlya-shkolnikov-5-7-klass/ — программа для школьников 5–7 класса: структура по возрастным группам, акцент на программу обучения, методику, расписание, цены, отзывы.
2. https://mymandarin.ru/kursy-kitajskogo-jazyka/dlja-detej/ — курсы для детей: блоки про преподавателей, форматы (группа/индивидуально), результаты обучения, FAQ.

При разработке использовать лучшие практики этих страниц: понятную структуру по возрастам/уровням, наглядную демонстрацию методики, социальные доказательства (отзывы, кейсы), четкие CTA.

## 4. Ключевые фразы (семантическое ядро)

Сгруппированы по смысловым кластерам для распределения по блокам и метатегам:

**Общие/нулевой уровень**
- китайский язык для детей
- китайский для детей
- китайский язык для детей с нуля
- китайский для детей с нуля онлайн

- уроки китайского языка для начинающих с нуля для детей
- обучение китайскому языку

**Онлайн-формат**
- китайский для детей онлайн
- школа китайского языка онлайн для детей
- изучение китайского языка онлайн для детей
- курсы китайского языка для детей (онлайн)
- изучение китайского языка для детей онлайн

**Уроки/курсы**
- курсы китайского языка для детей
- уроки китайского для детей
- уроки китайского языка для детей

**Гео (Москва)**
- курсы китайского языка для детей в москве

- подготовка к олимпиаде по китайскому языку

> Примечание: фразы должны органично распределяться по заголовкам H1–H3, метатегам и текстовым блокам без переспама — естественная плотность, синонимизация.

## 5. Структура страницы (блоки)

1. **H1 + Hero-блок**
   - H1: «Китайский язык для детей: курсы онлайн и в Москве с нуля»
   - Подзаголовок: краткое УТП (опытные преподаватели, игровая методика, подготовка к ЕГЭ/олимпиадам)
   - CTA: «Записаться на бесплатный пробный урок»
   - Форма заявки (имя, телефон/email, возраст ребёнка, формат: онлайн/Москва)

2. **Почему китайский язык для детей** (преимущества раннего изучения)
   - Короткие тезисы/иконки: развитие памяти, перспективы, интерес к культуре

3. **Программы обучения по возрасту/уровню**
   - С нуля (5–7 лет, 8–10 лет)
   - Школьники (11–14 лет)
   - Подготовка к ЕГЭ по китайскому языку
   - Подготовка к олимпиадам по китайскому языку
   - Для каждой программы: цель, длительность, формат занятий, что входит

4. **Формат обучения**
   - Онлайн (платформа, расписание, индивидуально/группа)
   - Очно в Москве (адрес/районы, расписание)
   - Сравнительная таблица форматов

5. **Методика преподавания**
   - Игровые элементы, иероглифика, аудирование, разговорная практика
   - Используемые материалы/учебники

6. **Преподаватели**
   - Карточки преподавателей: фото, опыт, специализация (дети, ЕГЭ, олимпиады)

7. **Результаты и отзывы**
   - Отзывы родителей/детей
   - Кейсы поступления/успехов на олимпиадах, баллы ЕГЭ

8. **Цены и тарифы**
   - Стоимость пробного занятия (бесплатно/символическая цена)
   - Пакеты абонементов (онлайн/очно)

9. **FAQ**
   - С какого возраста начинать?
   - Сколько времени нужно для базового уровня?
   - Нужны ли учебники?
   - Как проходит подготовка к ЕГЭ/олимпиаде?
   - Можно ли заниматься онлайн из других городов?

10. **Повторный CTA + контакты**
    - Форма заявки
    - Телефон, мессенджеры, адрес (для Москвы)
    - Карта (если есть офлайн-точка)

## 6. SEO-требования

- **Title**: «Китайский язык для детей с нуля — онлайн и в Москве | [Название школы]»
- **Description**: включает «курсы китайского языка для детей», «китайский язык для детей онлайн», «подготовка к ЕГЭ и олимпиадам по китайскому языку», CTA на пробный урок.
- **H1** — один на странице, содержит основной кластер запроса.
- **H2/H3** — для каждого тематического блока (программы, форматы, ЕГЭ, олимпиады, Москва).
- Alt-теги изображений — с упоминанием релевантных фраз («урок китайского языка для детей онлайн» и т.п.), без переспама.
- Внутренние ссылки на страницы конкретных программ (если есть отдельные лендинги по возрастам/ЕГЭ/олимпиаде).
- Микроразметка: Organization, Course, FAQPage, Review/AggregateRating.
- URL: понятный, например `/kitayskiy-dlya-detey/`.

## 7. Технические требования

- Адаптивная вёрстка (desktop/tablet/mobile).
- Форма заявки с валидацией полей, интеграция с CRM/уведомлениями (email/Telegram).
- Быстрая загрузка (оптимизация изображений, lazy-load).
- Кнопки CTA с возможностью А/Б-тестирования текста.
- Аналитика: Яндекс.Метрика/GA4, цели на отправку формы и звонки (если есть колл-трекинг).

## 8. Контент, который нужно подготовить

- Тексты для всех блоков (на основе кластеров ключевых фраз).
- Фото/иллюстрации преподавателей и учеников (с разрешением на использование).
- Видео-отзывы или скрины отзывов (опционально).
- Учебные материалы/скрины платформы для блока «Методика».

## 9. Метрики успеха

- Позиции по ключевым фразам из семантического ядра (топ-10 в течение 3–6 месяцев).
- Конверсия страницы в заявку (целевой показатель определяется отдельно).
- Снижение показателя отказов / увеличение времени на странице относительно текущих показателей.
